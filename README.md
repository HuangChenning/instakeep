# InstaKeep · IG 留存

Chrome 本机帖子备份测试版：批量下载用户主页帖子，或下载当前帖子的全部图片、视频及轮播项，可附来源 JSON。Reels 分类、快拍、精选暂不启用。

在 chrome://extensions 开启开发者模式，加载此目录。扩展内点击“选择保存目录”，在独立页面选择文件夹并授权写入；选择器默认从系统下载文件夹开始。文件直接写入所选目录，不使用 Chrome 下载设置。目录内支持子文件夹、文件名模板；同名文件保留。浏览器重启后可能需要重新授权。

打开帖子详情时，操作栏会出现“InstaKeep · 下载全部图片”图标，点击后直接下载全部轮播图片，并在帖子旁显示进度、完成结果或失败原因；混合轮播的视频由弹窗“全部内容”操作下载。此按钮需要 Instagram 页面访问权限。

批量备份前，在已登录的 Instagram 主页开启扩展下方临时观察，刷新并向下滚动一次，再查看观察结果。单帖任务从原帖页面开始。保持 Chrome 和原页面打开，可暂停、恢复及重试失败项。

`npm test` 当前 41 项通过。独立浏览器目录验证见 scripts/destination-check.mjs。实际用户目录已授权；从主页站内打开帖子后，点击页面按钮保存 3 张图片和来源 JSON 已真实验证成功，不打开设置弹窗；全量主页与真实视频写入仍待验证。检查点见 docs/progress.md。
